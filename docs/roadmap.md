# Roadmap

## Phase 1

Scaffold the application and documentation.

Goals:

- app shell
- navigation
- route scaffolding
- Prisma schema
- docs
- configuration foundations

## Phase 2

Implement source import and source pages.

Goals:

- local file import scaffold
- source list
- source detail
- extracted text placeholder
- source metadata storage

## Phase 3

Implement source segments and evidence scaffolds.

Goals:

- segment model usage
- evidence creation scaffold
- provenance UI foundations

## Phase 4

Implement claims.

Goals:

- claims page
- claim detail page
- claims inbox
- basic review actions scaffold

## Phase 5

Implement tensions and decisions.

Goals:

- tension list/detail
- decision list/detail
- relation display

## Phase 6

Implement outputs and stale scaffolding.

Goals:

- output list/detail
- output templates scaffold
- stale fields exposed in UI

## Phase 7

Implement Obsidian vault export.

Goals:

- deterministic folder structure
- markdown note generation
- dashboard note generation
- sync manifest foundations

## Phase 8

Implement bounded Obsidian import.

Goals:

- editable block parser
- write-back support
- sync record updates
- conflict state scaffold

## Phase 9

Refine workflow and reliability.

Goals:

- review UX improvements
- change log
- better stale signalling
- documentation updates
