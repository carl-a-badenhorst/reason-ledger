# Product Overview

## Product name

Reason Ledger

## Summary

Reason Ledger is an evidence-first reasoning workbench for turning messy source material into structured, reviewable claims, tensions, decisions, and outputs.

It is designed for knowledge work where trust, provenance, judgment, and change awareness matter more than passive accumulation.

## Core workflow

raw sources -> evidence -> claims -> tensions -> decisions -> outputs

## Core problem

Most knowledge systems are strong at storing material and weak at helping users make grounded decisions.

Reason Ledger addresses that gap by:

- preserving provenance
- distinguishing evidence from inference
- surfacing contradiction and uncertainty
- supporting review workflows
- tracking decisions
- generating scoped outputs
- detecting when updates may invalidate prior work

## Product boundaries

Reason Ledger is not:

- a generic note-taking tool
- a second-brain clone
- a wiki generator
- a graph visualisation product
- a chat-first retrieval interface

## Product architecture

The system has three layers:

1. canonical backend for structure and state
2. Next.js app for ingestion, review, and outputs
3. Obsidian vault projection for markdown-based working and navigation

## Primary users

Potential users include:

- researchers
- policy analysts
- curriculum designers
- strategists
- educators
- compliance teams
- product teams doing evidence-based decision work

## MVP goals

The MVP should make it possible to:

- import and inspect sources
- represent source segments and evidence
- review extracted claims
- track tensions
- record decisions
- generate basic outputs
- export structured notes to an Obsidian vault
- sync approved editable note sections back into the system
